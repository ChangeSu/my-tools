# my-tools 工具导航站 —— 方案与工单

Node.js 零依赖后端 + 静态导航页，自动扫描挂载目录下的 HTML 小工具并提供导航。

## 已确认决策

- 技术栈：Node.js 后端（尽量零依赖）+ 静态导航页
- 工具来源：挂载宿主机 `tools/` 目录，自动扫描，目录即注册
- 分类：`tools/` 一级子目录名即分类；根目录散落 HTML 归入"未分类"
- 页面功能：搜索过滤（与分类同批实现）、iframe 内嵌预览、最近使用/排序
- 部署：Docker（docker-compose 挂载工具目录）
- 仓库：https://github.com/ChangeSu/my-tools（issues 作为工单跟踪器）

## 工单拆分（tracer-bullet 垂直切片，按依赖顺序）

| 编号 | 标题 | Blocked by | 交付 |
|---|---|---|---|
| T01 | 项目脚手架 + 最小可演示导航 | 无 | Node 服务扫描 `tools/` 下 HTML，渲染最简导航列表，点击新标签页打开；Dockerfile 可构建；放 1 个示例工具即可演示"放文件→出现在导航" |
| T02 | 目录分类分组 + 搜索过滤 | T01 | 一级子目录=分类，导航按分类分组，散落文件归"未分类"；输入框按工具名/分类即时过滤 |
| T03 | iframe 内嵌预览 | T02 | 点击工具在站内 iframe 打开、可关闭返回；保留新标签页打开入口 |
| T04 | 最近使用与排序 | T03 | 记录打开过的工具，置顶"最近使用"，支持按名称/最近/最新排序 |
| T05 | Docker 部署交付 | T01 | docker-compose 挂载宿主机工具目录；README 覆盖构建、部署、添加新工具；docker 端到端验证 |
| T06 | 补充示例工具 | T02 | 2–3 个真实小工具（JSON 格式化、Base64 编解码等）放入不同分类作为验收样例 |
| T07 | 新增时间戳转换工具 | T06 | `tools/格式转换/时间戳转换.html`：双向换算（戳 ⇄ 日期时间）、秒/毫秒自动识别、本地/UTC 可选、实时当前戳、逐字段复制 |

T01 完成后，T02 与 T05 可并行；其余按链式推进。
